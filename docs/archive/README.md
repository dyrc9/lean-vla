# 历史文档归档

本目录保存当前论文正文不再使用的实验时间线、旧协议说明、旧论文叙事、历史图表、运行手册和各版本
checkpoint。归档只改变文档位置，不删除或改判任何冻结实验、non-pass 分类、checksum 或复现证据。

当前论文写作入口见 [`../README.md`](../README.md)。

## 顶层历史材料

- `progress_and_plan.md`：完整实验时间线；
- `failure_lessons.md`：失败原因与停止规则；
- `experiments.md`：旧实验协议与证据层级；
- `experiment_reuse.md`：历史证据复用边界；
- `implementation_and_experiment_readiness.md`：旧实现推进清单；
- `l2_and_cross_layer_experiments.md`：旧 L2/跨层实验计划；
- `semantic_subtask_pilot.md`：早期 semantic pilot；
- `remote_execution.md`：远程执行手册；
- `v11_*`、`v12_*`：历史 checkpoint 与优化过程。

## 论文历史材料

`paper/` 保存旧 preregistration、旧主表与图、旧 paper story、历史就绪度评估和旧 overhead 分析。
这些文件可用于 artifact appendix、复现审计或审稿问答，但不得作为当前论文正文和主表来源。
